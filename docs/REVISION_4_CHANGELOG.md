# Revision 4 changelog — 3D Galaxy Experience

## Summary
Expanded the 3D network from a generic secondary graph view into a defined galaxy-inspired, hierarchical exploration experience. Revision 1 archived documents remain unchanged; the active documentation is updated and this specification is authoritative for 3D work.

## Main changes
- Added `docs/3D_GALAXY_EXPERIENCE.md` as the complete product, interaction, rendering, data, performance, and acceptance specification.
- Defined nodes as rotatable luminous service/resource worlds and connections as glowing curved paths with meaningful endpoints/direction.
- Defined semantic constellations, deterministic spatial grouping, label/edge level of detail, and scale safeguards.
- Defined explicit “Explore inside” behavior: camera transition into actual modeled child scopes/local neighborhoods, breadcrumbs, back-one-level, return-to-overview, and context restoration.
- Explicitly separated containment hierarchy from communication relationships and prohibited fabricated interiors, edges, health, or traffic.
- Added requirements for data-bound simulated/observed activity, reduced motion, pause, WebGL/context-loss fallback, resource cleanup, and measured performance.
- Updated product spec, architecture, implementation plan, Milestone 4, Phase 08, visual language, animation polish, decisions, index, CLAUDE.md, and topology UI skill.

## Scope and delivery
This is a documentation update, not an implementation claim. The 3D work remains Milestone 4 and remains secondary to 2D usability. The implementation agent must inspect the real repository, implement incrementally, and report measured verification results.
